# 04 — 推荐落地页:朋友免登录查看专家信息

**What to build:** 朋友点开推荐链接,无需登录即可看到按 ops 配置展示的专家信息(从该专家的申报/简历解析数据取值,缺失字段降级,至少兜底"一位 GESF 专家")、项目介绍、"此链接由专家本人转发"的信任说明和明确的"开始申报"按钮。点击"开始申报"时推荐上下文被带入注册流程(cookie 或 URL 透传)。过期、已作废、不存在的链接展示统一、体面的失效页。每次点击(无论成败)记录点击日志。

**Blocked by:** 03 — 推荐 token ops 管理台

**Status:** ready-for-agent

- [ ] 公开解析 API(无鉴权):有效 token → 严格按展示配置返回字段(配置未勾选邮箱/电话时响应中绝不包含);过期/作废/不存在 → 统一失效语义
- [ ] 落地页:专家信息 + 项目介绍 + 信任说明 + "开始申报"按钮;数据缺失时优雅降级
- [ ] 失效页:过期与作废均有体面展示,不暴露技术细节
- [ ] "开始申报"点击将推荐上下文带入注册流程
- [ ] 每次点击记录日志(token、时间、IP、结果)
- [ ] route 测试:字段过滤严格性、失效语义、降级、点击日志
