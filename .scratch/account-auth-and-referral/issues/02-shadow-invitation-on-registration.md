# 02 — 影子邀请:注册即建申报,账号轨走通申报流程

**What to build:** 账号注册成功后,系统自动创建一张影子邀请(email 绑定注册邮箱,token 随机但永不暴露、永不用于链接登录)和一份挂在该邀请上的申报。已登录用户进入申报流程,简历上传、材料提交、状态查询与邀请链接用户完全一致;初审报告邮件发送到注册邮箱。影子邀请在数据上与普通邀请可区分,ops 档案中可识别。同一人的链接轨申报与账号轨申报不合并、不拦截。

**Blocked by:** 01 — 账号轨地基

**Status:** ready-for-agent

- [ ] 注册成功后(通过 Better Auth 数据库钩子/after-hook)事务性创建影子邀请 + 申报
- [ ] 影子邀请的 email 写入注册邮箱;其 token 通过任何链接访问路径都无法登录
- [ ] 影子邀请有可识别的来源标记,ops 档案中可与普通邀请区分
- [ ] 账号会话 → 申报的鉴权解析:账号轨用户访问申报页走账号分支,最终汇合到同一份申报数据;未登录访问被引导至登录
- [ ] 申报全链路(简历、分析、材料、初审、状态)对账号轨用户可用,与链接轨行为一致
- [ ] 初审报告邮件收件人解析命中影子邀请 email(注册邮箱)
- [ ] route 测试:注册→影子邀请+申报建立(email 绑定正确、token 不可链接登录);链接轨既有测试全绿
