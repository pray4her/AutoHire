# 03 — 推荐 token ops 管理台

**What to build:** ops 在专家档案后台为某位专家一键生成推荐链接:生成时自选落地页展示字段(目录固定为姓名/头衔/机构/邮箱/电话,联系方式默认不勾选,至少勾选姓名),界面有"该页面对任何拿到链接的人公开可见"的提示;生成后复制链接线下发送。每位专家同时至多一个有效 token;ops 可作废、续期(默认 90 天过期)、重新生成(旧链接立即失效)。token 为不透明随机串,数据库只存哈希,明文仅生成时展示一次。含推荐 token 表与点击日志表。复用 ops 密码登录鉴权。

**Blocked by:** None — can start immediately(与账号轨独立,可与 01/02 并行)

**Status:** ready-for-agent

- [ ] 推荐 token 表:哈希存储、关联专家、展示字段配置、状态(ACTIVE / DISABLED)、expiredAt(默认 90 天)、创建者;点击日志表
- [ ] 生成 API:展示字段配置持久化;每专家单 ACTIVE 约束(重新生成=旧 DISABLED+新建);明文 token 仅响应中返回一次
- [ ] 作废、续期、重新生成 API;未授权 ops 被拒
- [ ] ops 界面:生成表单(字段勾选+公开可见提示)、链接复制、状态/过期时间展示、作废/续期/重新生成操作
- [ ] 邮箱不出现在 token 中;token 随机性与邀请 token 同款
- [ ] route 测试覆盖上述全部行为(对照现有邀请生成 route 测试)
