# 05 — 推荐归因:注册绑定与 ops 可见

**What to build:** 朋友从推荐落地页点"开始申报"并在同一会话内完成注册时,其申报自动记录推荐归因(单值外键指向推荐 token)。无推荐上下文、上下文失效(token 已过期/作废)的注册正常申报、不记归因、不报错。归因一经建立不可被后续请求改写;已有申报不因事后点击推荐链接而补记。ops 在专家档案中看到每份申报的推荐来源,以及每个推荐 token 的点击→注册→申报转化漏斗。

**Blocked by:** 02 — 影子邀请;04 — 推荐落地页

**Status:** ready-for-agent

- [x] 申报表新增推荐归因外键(可空),含迁移
- [x] 注册完成时推荐上下文有效 → 申报挂归因;无效/无上下文 → 正常申报不记归因不报错
- [x] 归因不可改写;已有申报不补记
- [x] ops 专家档案显示申报的推荐来源(推荐专家)
- [x] ops 可见每个推荐 token 的点击/注册/申报转化数据
- [x] route 测试:归因绑定、无效上下文容错、归因不可变、ops 视图数据
