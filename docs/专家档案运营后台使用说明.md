# 专家档案运营后台 · 使用说明

> **读者**：运营、审核等业务同事（无需了解技术细节）  
> **对应页面**：专家档案（`/ops/expert-files`）  
> **更新说明**：本页已改为「账号 + 密码」登录；不再使用旧的 token 链接进入。

---

## 1. 这个页面是做什么的？

专家档案后台用于**内部查阅与打包下载**专家在申报过程中留下的材料，方便运营或审核同事：

- 按姓名、邮箱、客户编号查找专家
- 查看某位专家当前有哪些文件（只读，不能在此单文件下载）
- 把一位或多位专家的材料打成 **ZIP 压缩包** 下载到本地审阅

**注意：**

- 本页只服务「专家档案」；其他运营页面（如审计、邀约）入口与登录方式可能不同，请按各自说明使用。
- 列表中**只显示已分配客户编号**的申请；没有客户编号的记录不会出现在这里。

---

## 2. 如何进入与登录

### 2.1 打开登录页

在浏览器中打开专家档案登录地址（由项目负责人或技术同事提供），页面标题一般为 **「专家档案登录」**。

若直接打开档案主页但尚未登录，系统会自动跳转到登录页。

### 2.2 登录

1. 输入分配给您的 **用户名**
2. 输入 **密码**
3. 点击 **登录**

登录成功后进入「专家档案」主页面。

### 2.3 首次使用提示

- 初始账号与初始密码由管理员发放，请登录后尽快修改密码（见下文「修改密码」）。
- 请勿将账号密码发给无关人员；不用时建议点击右上角 **退出**。

### 2.4 退出

页面右上角点击 **退出**，即可安全离开。再次使用需重新登录。

## 3. 页面功能一览

主页面大致分为四块：

| 区域 | 作用 |
|------|------|
| 顶部 | 标题说明；**修改密码**、**退出** |
| 搜索 | 按条件筛选专家列表 |
| 结果 | 查看列表、勾选专家、打开详情 |
| 导出任务 | 查看打包进度、下载或重试 ZIP |

---

## 4. 如何搜索专家

1. （可选）在「姓名 / 邮箱 / 客户编号」中输入关键词  
2. 选择状态：
   - **全部**
   - **已提交**
   - **未提交**
3. 选择 **填写时间起 / 止**（按专家开始填写的时间筛选）  
   - 默认一般是**最近 7 天**
4. 点击 **搜索**

列表会显示匹配结果数量与当前页码。可用 **上一页 / 下一页** 翻页。

若提示「该范围内暂无申请记录」，可放宽时间范围或清空关键词后再试。

---

## 5. 如何查看某位专家的档案详情

1. 在结果表格中找到对应专家  
2. 点击该行的 **查看**  
3. 右侧会打开只读详情，包括：
   - 姓名、邮箱、状态、填写时间、提交时间
   - **文件夹**汇总（各目录下有多少文件）
   - **文件**清单（文件名、大小等）

**说明：** 详情里不能单独下载某一个文件；如需本地审阅，请使用下方的「导出」功能打成压缩包。

---

## 6. 如何导出 ZIP 压缩包

导出是**异步任务**：点击确认后，系统在后台打包，完成后可在「导出任务」区域下载。

### 6.1 导出方式

| 按钮 | 含义 |
|------|------|
| **导出匹配结果** | 按当前搜索条件，导出符合条件的专家（不必逐个勾选） |
| **导出已选（N）** | 只导出表格中勾选的专家；至少勾选 1 位 |

### 6.2 操作步骤

1. 先搜索或勾选好要导出的专家  
2. 点击「导出匹配结果」或「导出已选」  
3. 在弹出的 **确认导出** 窗口中核对：
   - 导出模式（按筛选 / 按勾选）
   - 可导出专家人数
   - 因「空档案」被排除的人数（没有可打包文件的会自动跳过）
   - 预估压缩包大小  
4. 点击 **开始导出**  
5. 到页面下方 **导出任务** 查看进度；需要时可点 **刷新**

### 6.3 下载与解压

- 任务状态为 **已成功** 或 **成功（有缺失）** 时，可点击 **下载**
- **下载链接约 1 小时内有效**；压缩包本身在系统侧大约保留 **7 天**
- 若文件夹名出现中文乱码，请使用 **7-Zip** 或 **WinRAR** 解压（不要只用系统自带解压）

「成功（有缺失）」表示整体已打好包，但个别文件可能缺失；解压后请对照文件夹内容核对。

### 6.4 导出限制（请业务侧知晓）

为避免一次打包过大或过久，系统有如下常见限制：

- 单次可导出专家人数有上限（当前约 **50** 人）
- 预估源文件总大小不能过大（当前约 **2GB**）
- 同一时间您这边通常只能有 **1** 个进行中的导出任务；若提示已有任务在进行，请等当前任务完成后再导出

超出限制时，请缩小时间范围、减少勾选人数后再试。

### 6.5 压缩包里大致有什么？

每位专家一般以 **客户编号** 为文件夹名，内部按材料类型分目录，例如：

- `0简历`
- `1基本信息`
- `2学历证明`
- `3工作证明`
- `4项目证明`
- `51论文` / `52著作` / `53专利` / `54会议` / `56荣誉`

具体以实际导出内容为准；没有上传材料的目录可能为空或不出现。

## 7. 导出任务状态说明

| 界面显示 | 含义 | 您可以做什么 |
|----------|------|----------------|
| 等待中 | 任务已创建，等待开始 | 稍等，可点刷新 |
| 进行中 | 正在打包 | 稍等，可点刷新 |
| 已成功 | 打包完成 | 下载 |
| 成功（有缺失） | 基本完成，但有个别文件缺失 | 下载后核对；必要时重试 |
| 失败 | 打包失败 | 查看失败原因；可点 **重试** |

失败原因会显示在任务卡片上。若多次失败，请记录提示文案并联系技术支持。

## 8. 如何修改密码

1. 登录后，点击右上角 **修改密码**  
2. 填写：
   - 当前密码
   - 新密码（至少 **8** 位）
   - 确认新密码（需与新密码一致）  
3. 点击 **保存**

修改成功后：

- 当前浏览器会话会刷新并继续可用  
- **其他已登录的地方会失效**，需用新密码重新登录

## 9. 常见问题

**Q：忘记密码怎么办？**  
请联系管理员或技术同事重置。页面上无法自助找回密码。

**Q：为什么搜不到某位专家？**  
常见原因：尚未分配客户编号；填写时间不在筛选范围内；姓名/邮箱拼写不一致；状态筛选选错（已提交 / 未提交）。

**Q：为什么导出时人数变少了？**  
确认窗口里的「已排除空档案」表示这些专家当前没有可打包文件，系统会自动跳过。

**Q：下载按钮点了没反应或提示不可下载？**  
可能链接已过期，或任务尚未成功。请刷新导出任务列表；若包已过期，可对同一任务点 **重试** 或重新发起导出。

**Q：旧的 token 链接还能用吗？**  
不能用于直接进入专家档案。请改用登录页的账号密码方式。

**Q：这和「审计后台 / 邀约后台」是同一个登录吗？**  
不是。专家档案使用**独立账号密码**；其他运营入口请按各自发放的方式进入。

## 10. 建议日常操作流程（速查）

```text
登录 → 设置时间范围并搜索 → 查看详情确认材料 → 勾选或按条件导出 → 等待任务成功 → 用 7-Zip/WinRAR 解压审阅 → 用完后退出
```

---

## 11. 需要技术同事配合的事项

以下内容一般由技术或管理员配置，业务同事知悉即可：

- 开通 / 重置账号与初始密码  
- 登录页完整网址  
- 导出环境是否可用（若导出长期失败，多半需技术侧排查）

如使用中遇到页面报错、无法登录或导出反复失败，请将**大致操作步骤**和**屏幕提示原文**发给技术支持，便于快速定位。
